# D-26-01135
The numerical example of D-26-01135

1. The "Empirical Example" folder contains the datasets used.
2. "solve_table1.m" and "solve_table2.m" is the code used to calculate the cases described in the text.
3. "Numerical_example_local_ICE.m" and "Numerical_example_global_ICE.m" is the code used to calculate the ICE iteration in Section 5.1
4. "Synthetic_network_scalability_benchmark_for_weighted_cost_ICE.m" is the code for comparing the efficiency of the ICE algorithm in Section 5.1 of the article. "Synthetic_network_scalability_benchmark_for_weighted_cost_ICE.mat" is the corresponding data after running. By directly reading it into MATLAB and plotting the image, one can obtain the comparison image of the article.
5. The content in Folder "Number Examples" is the 5.2 section of the article. It contains the code for solving c_z, c_I and verifying the existence of the core and satisfactory solution, and for drawing the graphs.

1. “Empirical Example”文件夹包含所使用的数据集。
2. “solve_table1.m” 和 “solve_table2.m” 是用于计算文中所述情况的代码。
3. “Numerical_example_local_ICE.m” 和 “Numerical_example_global_ICE.m” 是用于计算第5.1节中 ICE 迭代的代码。
4. “Synthetic_network_scalability_benchmark_for_weighted_cost_ICE.m” 是用于比较文章第5.1节中 ICE 算法效率的代码。而 “Synthetic_network_scalability_benchmark_for_weighted_cost_ICE.mat” 是运行后生成的对应数据。通过直接在 MATLAB 中读取该文件并绘制图像，即可获得文章中的对比结果图。
5. “数字示例”文件夹中的内容是文章的第5.2节，包含用于求解c_z、c_I并验证核心存在性和满意解的代码，以及绘制图形的代码。
